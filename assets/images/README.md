# Images (per-language vocabulary photos)

Each subfolder holds one image per vocabulary item, named after the item id
without its language prefix. For example, item `es-agua` → `es/agua.png`.

```
assets/images/
  es/   agua.png  pan.png  cafe.png ...
  fr/   eau.png   pain.png cafe.png ...
```

- The images currently here are **placeholders** generated by
  `npm run gen:images`. Replace any of them with a real photo **using the same
  filename** — no code changes needed (the registry keys are the item ids).
- The registry `src/content/assets/imageAssets.ts` maps item id → image via a
  static `require()` (Metro requires literal paths). It is regenerated by
  `npm run gen:images`.
- Resolution order in `src/components/Visual.tsx`: bundled image → item's remote
  `image` URL → emoji. Supported formats: png/jpg/webp (whatever RN supports).
